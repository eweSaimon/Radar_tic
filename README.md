# Radar TIC

Prototipo Front-End en Angular que centraliza oportunidades academicas y profesionales.

## Requisitos
- Node.js 20 o superior
- Angular CLI (`npm install -g @angular/cli`)

## Ejecución
1. `git clone https://github.com/eweSaimon/radar-tic.git`
2. `cd radar-tic`
3. `npm install`
4. `ng serve`
5. Abrir http://localhost:4200

## Arquitectura
oportunidades.json  HttpClient  OportunidadesService  App  Signal  @for  OportunidadCard  input() / output()
